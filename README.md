This project evaluates machine learning models on a dataset of car reviews using the Hugging Face ecosystem (`transformers` and `evaluate`). It performs four NLP workflows: **sentiment analysis evaluation**, **machine translation with BLEU scoring**, **extractive question answering**, and **text summarization with bias/toxicity metrics**.

---

## 1. Overall Purpose

The script performs a series of Natural Language Processing (NLP) tasks on a dataset of car reviews (`car_reviews.csv`). It serves as an end-to-end evaluation pipeline that tests how various pre-trained language models handle text classification, translation, information extraction, and summarization, alongside safety and alignment evaluations (toxicity and bias monitoring).

---

## 2. Step-by-Step Code Execution

The execution is split into 5 chronological phases:

1. **Sentiment Analysis & Performance Evaluation:** Lines 1–19.
Loads a dataset of car reviews and evaluates a fine-tuned DistilBERT model. It runs predictions on the dataset, maps the textual labels to binary formats, and calculates the model's accuracy and F1-score against ground truth values.


2. **English-to-Spanish Translation & BLEU Scoring:** Lines 21–44.
Takes the first car review and translates it using an explicit Seq2Seq model framework (without high-level pipelines). It then reads human reference translations from a text file and computes a BLEU score to assess the translation's linguistic quality.


3. **Extractive Question Answering:** Lines 46–69.
Isolates the second car review (`reviews[1]`) as a context block. It feeds the context and a hardcoded question into a MiniLM model trained on SQuAD2.0, calculates the token logits representing the start and end positions of the answer, and extracts the text span.


4. **Text Summarization:** Lines 71–89.
Extracts the very last review in the dataset and passes it through a BART-large model configured with beam search optimization to generate a concise, shortened summary.


5. **Safety & Bias Analysis:** Lines 91–105.
Evaluates the newly generated summary text using the Hugging Face `evaluate` library. It calculates a toxicity score to verify safe text generation and a regard score to assess demographic or systemic bias within the summary.

## 4. Key Functions and Methods

### Framework/Built-in Methods

* `pd.read_csv()`: Standard Pandas function that parses structured CSV text documents into a flexible tabular DataFrame format.
* `text["Review"].tolist()`: A data conversion method that isolates a single column vector from a Pandas DataFrame and reformats it into a standard Python list.
* `with open() as file:`: Context manager handling clean, safe I/O file streams, ensuring resources close safely once reading processes complete.

### Hugging Face Ecosystem APIs (`transformers` & `evaluate`)

* `pipeline()`: High-level API utility wrapper encapsulating raw boilerplate code needed to initialize tokenizers, download architectures, format parameters, and deliver clean inference outputs.
* `AutoTokenizer.from_pretrained()` / `AutoModelFor...from_pretrained()`: Factory class components instantiated dynamically to auto-detect, download, cache, and inject the structural layouts needed for models.
* `mt_tokenizer()` / `tokenizer()` / `sum_tokenizer()`: Functional objects that ingest plain-text strings to strip tokens, map indices, append padding buffers, and slice text length boundaries down to match maximum engine capacities.
* `mt_model.generate()` / `sum_model.generate()`: Generative token sequences that utilize advanced search space routines (such as Beam Search configurations) to output auto-regressive tokens for language synthesis.
* `tokenizer.decode()` / `tokenizer.batch_decode()`: De-serialization sequence converters that invert lookup maps, stripping structural control variables (`skip_special_tokens=True`) to produce human-readable strings.
* `evaluate.load()`: Module constructor factory patterns fetching evaluation metrics (such as BLEU scoring structures or toxicity scoring vectors) from remote file paths or local storage registries.
* `metric.compute()`: Statistical processing calculations mapping target models, truth sets, and raw data parameters into comparative analytical performance dictionaries.

### Matrix Operations (`torch` & `scikit-learn`)

* `with torch.no_grad():`: Context configuration setting that disables tracking autograd gradient histories, reducing compute overhead during strict inference loops.
* `torch.argmax(dim=-1).item()`: Tensor reduction sequence extracting the highest numeric confidence prediction index out from vector sets, converting tensors back to standard Python integer structures (`.item()`).
* `accuracy_score()` / `f1_score()`: Standard performance metric evaluation handlers measuring predictive success rates by mapping arrays of correct answers against raw models output vectors.
